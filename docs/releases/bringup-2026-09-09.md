## Notes (the release body)

**One LIF neuron from `neuralos-snn` ran on an ESP32-C3 (RISC-V
rv32imc) on 2026-09-09.** Board: a SuperMini, esp32c3 rev v0.4. Read
from the board's serial line, banked in `evidence/esp32c3-bringup/`:

- 1,501 ns per neuron step (10,000-step burst, decay + integrate,
  i16 fixed-point, no float).
- First spike at step 56 of the real-time loop (host prediction 55;
  the loop stamps wall time, one step costs 1.0057 ms).
- 147 spikes in the 10,000-step burst = 14.7 spikes/s, the host's
  number exactly; 14.67/s sustained over 20 s.
- The blue LED blinks.

**`neuralos-nir2json` is the stranger-ready tool:** a pure-Rust,
statically linked converter from `.nir` (the Neuromorphic Intermediate
Representation, HDF5) to the library's JSON graph. No Python, no C
HDF5. It converts Linear/LIF graphs that snnTorch, norse or rockpool
emit, refuses what it cannot represent with the node and parameter
named (simulation-unit LIF parameters need `--sim-units`; lzf-filtered
files are refused by name), and stamps a sidecar with what it widened.
Details and the conventions wall: `crates/neuralos-nir2json/README.md`.

Rebuild either artifact from source: the tool by its README § Build,
the firmware by `evidence/esp32c3-bringup/README.md` § Rebuild. Under
the pinned toolchain and the committed locks, the shas in the attached
`SHA256SUMS` reproduce.

What this release is not: not a new library version (the library is
unchanged at `0.1.0-alpha.5`), not a benchmark (one neuron, one
board), not a claim about the network layer on the chip.

## Appended 2026-09-10 (ISA rounds 23 and 24); the notes above unchanged

- "Both shas were reproduced": true that day, in the same target dir.
  The ELF sha pins a build, not a source state: the app descriptor
  carries a build stamp (`esp-bootloader-esp-idf`'s build script,
  `SOURCE_DATE_EPOCH` or the wall clock) and the symbol hashes follow
  the clone path. The code section is what a rebuild is compared
  against: `.text` sha `d14cce25…` for this ELF, reproduced
  byte-identical from a clone at another path. Record:
  `evidence/esp32c3-bringup/README.md` § Rebuild + run.
- "1,501 ns per neuron step": true for this binary. Re-measured on the
  alpha.6 spine on 2026-09-10: 2,842 ns/step, every behavior figure
  identical. Read from both flashed ELFs, the alpha.5 burst loop was
  one the compiler kept in registers; 2,842 is the in-memory cost any
  network pays on either version. ISA round-23.
- The attached firmware ELF embeds 16 `/home/<user>/…` panic-location
  paths; left standing by ruling (replacing a published asset breaks
  its holders' verification for nil sensitivity). ISA round-23
  addendum; the scrub of the tree is round-24.
