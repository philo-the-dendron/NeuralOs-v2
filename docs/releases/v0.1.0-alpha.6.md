### Scrub

The flashed ELF (`e26e1749…`, built `--locked` on `820d81a`, the
binary that produced the log) embeds 17 `/home/<user>/…`
panic-location paths, the repo's personal-string class. The asset is
that ELF with the 14-byte `/home/<user>/` prefix overwritten in place
by `/redacted-usr/` (same length, 17 occurrences): file size and
layout unchanged, every section but the path strings byte-identical,
the `.text` sha equal to the pin in the evidence README. The
unscrubbed original is kept privately and is not published. The
production is one Python replace over the bytes; it is not
reproducible from source (the ELF sha carries a build stamp and
path-dependent symbol hashes, evidence README § Rebuild + run), so
the `.text` sha is what a rebuild is compared against. ISA round-23
addendum (the ruling), round-25 (this asset).

## Notes (the release body)

**`neuralos-snn` 0.1.0-alpha.6** — the `no_std`, i16 fixed-point
spiking-neuron library for RISC-V edge silicon.

Since alpha.5:

- **The spike history is a `[u32; N]` ring.** O(1) push, the oldest
  entry overwritten once full. It replaces `heapless::Vec`, whose
  `remove(0)` shifted the whole buffer on every spike past the 64th;
  proven by a differential proptest against the pre-ring history kept
  verbatim as the oracle. No public API moved.
- **No runtime dependencies.** The crate depends on `core`.
- **`rust-version = "1.92"` declared**, the toolchain pin.
- **`isi_stats_us` sums in `u128`** (test-gated): three intervals
  above 2^32/√3 overflowed the `u64` sum of squares; the differential
  test now runs on arbitrary `u32` times.

**Measured on the ESP32-C3 (rv32imc, 160 MHz), same SuperMini and
same firmware source as the bring-up release:** every behavior figure
identical to alpha.5 (147 spikes in the 10,000-step burst, first
spike at step 56, 14.7 spikes/s), and the burst costs **2,842 ns per
neuron step**, against 1,501 ns measured on alpha.5. Read from the
two flashed binaries: the alpha.5 burst loop was one the compiler
happened to keep in registers, with one 64-bit software division per
step; alpha.6's keeps the neuron in memory and pays two, plus a
hardware `divu`, which is what a `Vec<LIFNeuron>` network pays on
either version. The library did not get slower in the general case;
the honest number is the higher one, and narrowing those divisions,
bit-exact, is the next brief. Mechanism, listings and pins:
`evidence/esp32c3-bringup/README.md` § The mechanism.

**The attached binary** is the firmware that produced that
measurement, with its embedded home paths overwritten in place (same
length; the code section is byte-identical to the flashed one, sha in
`SHA256SUMS` and in the evidence README). Rebuild from source by the
evidence README § Rebuild + run; compare the `.text` section, not the
file.

What this release is not: not a benchmark (one neuron, one board),
not a claim about the network layer on the chip, not a change to any
published number of the paper.
